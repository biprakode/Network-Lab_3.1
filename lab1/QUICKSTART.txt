TROUBLESHOOTING:
----------------
  Q: "Connection refused"
  A: Start receiver first in Terminal 1, wait 1 second before starting sender

  Q: "All frames rejected"
  A: Make sure both sender and receiver use SAME scheme (e.g., both crc32)

  Q: "Files don't match"
  A: Should never happen if all frames are ACCEPTED - check diff output

  Q: "Port already in use"
  A: Wait a few seconds for port to be released, or: killall receiver

  ✓ Last frame may have partial payload

BUILD EVALUATION BINARY:
------------------------

RUN EVALUATION (Test error detection across 4 scenarios):
---------------------------------------------------------
  ./eval [trials]

  Examples:
  • ./eval                # Default 1000 trials per test
  • ./eval 10000         # 10,000 trials per test
  • ./eval 1000000       # 1,000,000 trials for deep statistical analysis

WHAT GETS TESTED:
-----------------

1. ALL-ZERO BLIND SPOT (Checksum)
   → All-zero payload + zero checksum field
   → Expected: UNDETECTED by checksum (checksum by-design blind spot)
   → Why: One's complement rule: 0 + 0 = 0 (matches expected)

2. COMPENSATING ERRORS (Checksum-blind)
   → Paired bit flips in two different 16-bit words at same position
   → Expected: Checksum ~0%, CRC 100%
   → Why: Checksum only sees total sum (linear); CRC sees bit patterns (GF(2))
   → Tests: All 4 CRC degrees (8, 10, 16, 32)

3. GENERATOR MULTIPLE ERRORS (CRC-blind)
   → XOR generator polynomial into data
   → Expected: CRC ~0%, Checksum 100%
   → Why: CRC sees polynomial multiple (still divides evenly); checksum sees sum change
   → Tests: All 4 CRC degrees (8, 10, 16, 32)

4. BURST ERRORS AT BOUNDARY (CRC)
   → Consecutive bit flips at burst length = r (degree) and r+1
   → Expected Burst at r: 100% detection
   → Expected Burst at r+1: ~(100 - 100×2^(-r))% detection
     * CRC-8: ~99.6% (0.4% miss rate on polynomial-aligned bursts)
     * CRC-10: ~99.9%
     * CRC-16: ~99.998%
     * CRC-32: ~99.999999%
   → Tests: All 4 CRC degrees
